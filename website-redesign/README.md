# BidBundle Modern & Clean — Final Updated Folder

This standalone HTML/CSS/JavaScript prototype includes the cumulative Modern & Clean landing-page changes:

- Navy, teal, amber, and neutral design system
- Responsive desktop, tablet, and mobile layouts
- Mobile vertical scrolling and safe-area spacing
- Modern hero, neighborhood illustration, KPI cards, live activity, workflow, and service sections
- Scroll reveals, animated counters, connection paths, and subtle card motion
- Contact call-to-action and complete responsive footer
- Demo contact details that can be replaced later
- Custom SVG icons and illustrations

## Main files

- `index.html`
- `styles.css`
- `app.js`
- `assets/icons/`
- `assets/illustrations/`

## Run locally

```bash
python3 -m http.server 8080
```

Open `http://localhost:8080`.
